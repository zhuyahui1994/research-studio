# 贡献指南

感谢参与研析台。这个项目优先保持单文件、前端本地处理和中文学术工作流的一致性。

## 提交前检查

- 不引入服务端上传、远程数据库或隐藏的数据上报。
- 新功能需要在没有数据、只有演示数据、数据缺失和窄屏下都能工作。
- 统计结果应显示适用场景、解释边界和必要的样本条件。
- 导出文件应使用清晰的中文文件名，并能在主流浏览器触发下载。
- 修改现有功能时保留旧项目 JSON 的兼容读取。

## 提交方式

1. 从默认分支创建特性分支。
2. 在浏览器中验证主要交互和移动端布局。
3. 在 Pull Request 中说明影响的模块、验证步骤和已知限制。

## 代码风格

应用使用原生 JavaScript、模板字符串和局部函数组织模块。请优先复用现有状态、导出和日志 API，避免为了小功能引入新的框架或构建步骤。

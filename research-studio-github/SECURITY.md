# 安全与隐私

研析台默认在浏览器本地处理数据，不提供业务服务器，也不会主动上传问卷、报告或项目内容。

请注意：

- CDN 依赖会向对应的公共 CDN 请求脚本资源；离线环境需要自行提供这些依赖。
- 使用网页抓取时，浏览器会直接请求用户输入的公开 URL，目标网站可能记录该请求。
- 浏览器 `localStorage` 不是加密存储。多人共用设备时，请导出备份后清理浏览器站点数据。
- 不要在公开仓库中提交包含真实个人信息、身份证号、联系方式或未脱敏问卷的 JSON / CSV。

发现安全问题时，请先通过 GitHub Private Vulnerability Reporting 或维护者私下联系，不要直接公开可利用细节。

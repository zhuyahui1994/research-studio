# 研析台用户手册

## 1. 开始使用

首次打开后按快速引导完成三件事：上传优秀报告或 PPT、新建项目、按步骤分析。顶部“本地自动保存”按钮可打开存储中心，检查浏览器容量、依赖状态和 IndexedDB 镜像。

## 2. 数据安全

- 每次修改会写入 `localStorage`，并异步镜像到 IndexedDB。
- 正式分析前建议在存储中心导出加密备份。
- 忘记加密备份密码后无法恢复，应用不会保存密码。
- 共享电脑上的 localStorage 和 IndexedDB 不加密，使用结束后应导出并清空本地数据。

## 3. 数据导入

支持 CSV、XLSX、粘贴数据和公开网页抓取结果。导入后会生成数据健康分，重点检查：

- 重复或空表头；
- 样本量和整体缺失率；
- 混合类型、常量列和重复行；
- 疑似 Likert 量表越界。

健康分不是统计质量的最终结论，低分项需要结合问卷编码表人工检查。

## 4. 统计前提

假设检验会根据方法显示 Jarque–Bera 正态性、Levene 方差齐性、样本量或卡方期望频数。回归会报告 VIF、残差正态性和 Durbin–Watson。

前提未满足时，应考虑变量变换、稳健标准误、非参数方法或重新设计模型，而不是只保留显著结果。

## 5. 问卷与量表

量表库提供满意度、忠诚度、感知价值、购买意愿和价格敏感度题项及引用。平台导入 CSV 可作为问卷星、腾讯问卷等平台的整理底稿，具体导入格式仍应按平台最新规范调整。

反向计分默认生成新列并保留原始列，计算公式为 `最高分 + 1 - 原值`。

## 6. 报告和答辩

报告支持比赛、学术和商业三种模板。章节可拖动排序，也可编辑摘要、关键词、局限和参考文献。

- “导出 PDF”适合稳定版式。
- “可搜索文本 PDF”会打开打印页，通过浏览器“另存为 PDF”保留可复制文本。
- 答辩准备包包含报告 PDF、PPTX、演讲备注、问题清单和项目备份。

## 7. 离线使用

通过 GitHub Pages 或其他 HTTP 静态服务器访问一次后，Service Worker 会缓存应用壳和已成功获取的 CDN 依赖。直接双击 `file://` 打开时浏览器不允许注册 Service Worker，因此不能保证完整离线能力。

## 8. 项目锁定与协作

在项目菜单中可设为只读，避免现场演示误改。历史面板支持按步骤和成员筛选日志，版本页显示数据行数、变量数和结果模块数的变化。
